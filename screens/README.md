# Screenshots

Drop image files here so the root [`README.md`](../README.md) screenshot section can resolve them on GitHub.

## Recommended filenames

Use PNG or WebP. Match these names so you do not need to edit the main README table paths:

| File | Suggested content |
|------|-------------------|
| `01-home.png` | Home / hub, scan CTA, bottom navigation |
| `02-library.png` | Library with tabs or search |
| `03-now-playing.png` | Now playing, progress, controls |
| `04-equalizer.png` | EQ bands and preset chips |
| `05-files.png` | File explorer (optional if you use that flow) |
| `06-settings.png` | Settings / About |

After adding files, commit and push. If you prefer different names, update the image paths in `README.md` (table + inline `![...](...)` lines) to match.
